#Real-Time Collaborative Code Editor
A collaborative coding platform where multiple users can write and edit code together in real time. The application supports live synchronization and code execution functionality.

#Features
Real-time collaborative editing
Multi-user synchronization
Code execution support
Room-based collaboration
Responsive UI


#Tech Stack
Frontend
React.js
Tailwind CSS
Backend
Node.js
Express.js
Socket.IO

#APIs
JDoodle API

#How It Works
Users join a coding room
Changes are synchronized using Socket.IO
Code can be executed using JDoodle API
Future Improvements
Video/audio collaboration
Syntax highlighting improvements
User authentication
Code saving functionality
